Security finding

The affected DNS configuration was still pointing to an old GitHub username after the original account owner changed their username. Since that username became available for registration, I was able to create an account using it and host this page on the associated repository.

This is a harmless proof of concept to show what can happen when an old CNAME record is left pointing to a resource that is no longer controlled by the original owner.

Sorry for the little surprise! ❤️

No harm intended — just a friendly reminder to update the CNAME and remove the dangling reference.
